# AgntSpark brand

The mark is an **A whose crossbar is a spark**: the A for AgntSpark, the spark
for what an agent does once it's running.

Regenerate everything below with `python3 brand/build.py` (needs `fonttools`,
plus `rsvg-convert` and ImageMagick on PATH). Edit the mark's paths or colors
there, never in the generated files.

## Files

| File | Use it for |
|---|---|
| `agntspark-logo.svg` / `png/agntspark-logo-*w.png` | Mark + wordmark on light backgrounds |
| `agntspark-logo-light.svg` / `png/agntspark-logo-light-*w.png` | Mark + wordmark on dark backgrounds |
| `agntspark-mark.svg` / `png/agntspark-mark-*.png` | Mark alone on light backgrounds |
| `agntspark-mark-light.svg` / `png/agntspark-mark-light-*.png` | Mark alone on dark backgrounds |
| `agntspark-icon.svg` / `png/agntspark-icon-*.png` | App icon: rounded dark tile (favicons, docs, slides) |
| `agntspark-icon-square.svg` / `png/agntspark-icon-square-*.png` | Full-bleed square for avatars that apply their own mask (LinkedIn, X, GitHub, Google) |
| `agntspark-social.svg` / `png/agntspark-social-1200x630.png` | Link preview image (Open Graph / Twitter) |
| `agntspark-header-1500x500.svg` / `png/agntspark-header-1500x500.png` | Profile header for X and LinkedIn; content sits right, clear of the avatar |

The site root also carries `favicon.ico` (16/32/48), `favicon.svg`,
`apple-touch-icon.png`, `icon-192.png`, `icon-512.png`, `og-image.png` and
`site.webmanifest`, all generated by the same script.

## Colors

| Name | Hex | Where |
|---|---|---|
| Ink | `#141412` | The A and wordmark on light backgrounds; icon tile |
| Paper | `#EEECE6` | The A and wordmark on dark backgrounds |
| Spark | `#FF5A1F` | The spark. Always this color, on every background |
| Cream | `#FAF9F6` | Page background |

## Type

Wordmark: Geist SemiBold, tracking −3%, converted to outlines. Site text uses
Geist and Geist Mono.

## Usage

- **Clear space:** keep at least the width of the spark (about a quarter of
  the mark's height) empty around the logo.
- **Minimum size:** mark 16 px tall; logo 96 px wide.
- Don't recolor the spark, stretch or rotate the mark, add effects, or set the
  wordmark in another font.
- On photos or busy backgrounds, use the app icon rather than the bare mark.
